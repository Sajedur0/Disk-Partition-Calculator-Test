How the numbers work
• 1 GB = 1024 MB, exactly what Explorer shows.
• The typed value = visible size + 4 MB formatter slack.
• Windows Setup system partitions ≈ 566 MB (100 EFI + 16 MSR + 450 Recovery).
• FAT32 stops at 32 GB in the format tool and 4 GB per file.
• MBR disks accept only 4 primary partitions — use GPT.

This mock is a design reference, not the app. The Android UI is Jetpack Compose (ui/components/LiquidGlass.kt), where the frost is produced by re-sampling the animated backdrop through Modifier.blur.
