# Flutter → Kotlin / Jetpack Compose Migration

This repository used to be a Flutter app (`lib/`, `pubspec.yaml`, Dart widgets). It is now a native
Android app written in Kotlin with Jetpack Compose.

**What did not change:** every calculation, every constant, every user-visible string, the
`SharedPreferences` keys and the JSON shape of the saved history. An update of the old app keeps its
settings and its calculation history.

**What changed:** the whole UI layer was rebuilt with Compose — Material 3 components, a real
navigation bar, Material Symbols icons, a refreshed colour/typography scale and a circular theme
reveal that grows from the tapped point.

## Behaviour parity notes

Kept identical on purpose:

1. **Math** — same constants (`1024` MB/GB, `4` MB per-partition overhead, `566` MB System Reserved),
   same `round()` boundaries, same `ArgumentError`-style failure text
   (`Invalid argument(s): Total size too small for the requested partition count`).
2. **Copy** — all labels, warnings, snack bars, dialogs, share text, privacy policy and about text
   are carried over verbatim from the Flutter version, including its typographic characters (`…`,
   `×`, the `❤️`/`🇧🇩` line) and its plural handling (`1 partitions`).
3. **Storage** — history key `conversion_history` (JSON array with `id`, `inputValue`, `fromUnit`,
   `toUnit`, `filesystem`, `requiredInputMb`, `result`, `timestamp`, `splitCount`,
   `splitPartitionGb`, `splitPartitionMb`, `splitPartitionDisplayMb`), settings keys
   `theme_mode`, `settings_default_filesystem`, `settings_default_simulation`, and the enum ordinals
   (`system = 0`, `light = 1`, `dark = 2`). Zone-less timestamps written by the Dart app still parse.
4. **Flow** — start in light mode unless a preference exists, 100 entry history cap, 1-8 partitions,
   FAT32 warnings above 32 GB, quick presets 20/50/100/250/500/1024 GB, "1 TB" label for 1024 GB,
   2 s delayed update check plus checks on resume, mandatory update after 5 stale days.
5. **Dialogs** — the result dialog keeps the same rows, the same `Enabled (566 MB hidden overhead)` /
   `Disabled` values, the same explanation ordering (Windows Setup note, FAT32 size warning, FAT32
   file size note) and the same copy-to-clipboard action.

Deliberate UI differences (the redesign):

1. **Bottom navigation bar** instead of a top `TabBar` — Material 3 pattern for three peer tabs.
2. **Material Symbols** vector icons instead of Material Icons from a font.
3. **Expressive structure** — section headers with an accent bar, tonal icon tiles, sliding filesystem
   segmented control, animated hero number in the result dialog, animated tab transitions and a
   subtle haptic on tab/theme changes.
4. **Circular theme reveal** is now a Compose draw-time clip of the live tree, so the new theme
   animates in from the tapped pixel.
5. **Version label** comes from `BuildConfig` (no `package_info_plus` dependency).
6. **Settings entry points stay as they were** — "Share App", "Privacy Policy", "Rate Us" (Play Store
   listing) and "About", while the Privacy Policy page keeps its "App" / "Developer" / "Email"
   contact rows and their exact links.
